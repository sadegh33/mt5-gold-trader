# MT5 Gold Trader - Telegram bot + web dashboard + EA (MVP)

This repository contains the MVP implementation of a Gold trading assistant with:

- Signal generation (EMA(20/50) + RSI)
- Telegram bot for notifications and basic management
- Web dashboard with live chart (TradingView widget)
- EA skeleton (MQL5) to forward ticks and receive webhooks for automated execution

See docs/INSTALL.md for quick setup instructions.
